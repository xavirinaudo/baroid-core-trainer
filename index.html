CARBONOX Thinner / Filtration control Alkali-treated lignite. Thins mud and controls filtration in WBF at high temperatures.

QUIK-THIN Thinner / Deflocculant Modified ferrochrome lignosulfonate. Disperses clays, reducing yield points and gel strengths. Requires alkaline pH.

Exam Formulas & API Rules

1. Alkalinity Ionic Tables (API 13B-1)

- Pf = 0: OH⁻ = 0 | CO₃²⁻ = 0 | HCO₃⁻ = 1200 * Mf
- Pf = Mf: OH⁻ = 340 * Pf | CO₃²⁻ = 0 | HCO₃⁻ = 0
- 2Pf = Mf: OH⁻ = 0 | CO₃²⁻ = 1200 * Pf | HCO₃⁻ = 0
- 2Pf > Mf: OH⁻ = 340 * (2*Pf - Mf) | CO₃²⁻ = 1200 * (Mf - Pf) | HCO₃⁻ = 0
- 2Pf < Mf: OH⁻ = 0 | CO₃²⁻ = 1200 * Pf | HCO₃⁻ = 1200 * (Mf - 2*Pf)

2. Barite Mass Balance (100 lb/sack)

- Weight-up only (Volume increases):
    Sacks = V1 * 14.7 * (W2 - W1) / (35 - W2) (Field approximation)
    Final Volume V2 = V1 * (35.05 - W1) / (35.05 - W2) (Exact Volume)
- Weight-up keeping final volume V_final constant:
    Mud volume to keep V_keep = V_final * (35.05 - W2) / (35.05 - W1)
    Mud volume to dump V_dump = V_final - V_keep
    Sacks = V_keep * 14.72 * (W2 - W1) / (35.05 - W2) (Exact Sacks)

3. Triplex Pump Performance

- Formula: Output (bbl/stk) = 0.000243 * (Liner diameter)² * Stroke length * Efficiency
- Example: 6.5" Liner, 12" Stroke, 96% Efficiency:
    Output = 0.000243 * (6.5)² * 12 * 0.96 = 0.1183 bbl/stk
